# Todo React Avançado

Aplicação de lista de tarefas desenvolvida com React, Vite e Tailwind CSS.

## Funcionalidades

- Adicionar tarefas.
- Concluir e reabrir tarefas.
- Remover tarefas.
- Filtrar tarefas.
- Limpar tarefas concluídas.
- Acompanhar indicadores de progresso.
- Salvar tarefas no navegador.

## Tecnologias

- React
- JavaScript
- Vite
- Tailwind CSS
- Context API
- React Hooks

## Executar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor:

```bash
npm run dev
```
